# ビートスマッシュ Beat Smash

ローカル対戦のパーティ格闘に、軽いリズム要素を足した HTML5 Canvas の MVP です。オンラインもストーリーもありません。1〜4人で、1ラウンド約50秒。ビートが光った瞬間の攻撃（ジャスト）は、ダメージも吹っ飛びも強くなります。

四角いキャラが1つのケージでぶつかります。最後まで立っていた人、時間切れなら残りHPが多い人が勝ちです。音はブラウザの合成音で、画像などの外部アセットはありません。`index.html` と `src/` があればオフラインで遊べます。

## 起動

依存のインストールは不要です。

`index.html` をブラウザで直接開くか、このフォルダで:

```bash
python -m http.server
```

表示された URL（例: <http://127.0.0.1:8000>）を開きます。

開発サーバを使う場合:

```bash
npm install
npm run dev
```

<http://127.0.0.1:4721> で同じゲームが開きます。

## 操作

メニューで人数を選んで **ファイト！**（または Enter）。

| | 移動 | 弱攻撃 | 強攻撃 | 回避 |
| --- | --- | --- | --- | --- |
| P1 ドン | WASD | J | K | L |
| P2 パチ | 矢印 | I または テンキー1 | O または テンキー2 | P または テンキー3 |
| P3 / P4 | ゲームパッドのスティック / 十字 | A（Cross） | B（Circle） | X（Square）または RB |

- 上でジャンプ、下で急降下。
- 画面上部の輪が芯に重なり、枠とキャラが **金色** のあいだに攻撃するとジャスト。ヒットストップが長く、大きく吹き飛びます。
- 外すと弱いヒットです。回避中は無敵。
- 3・4人目のパッドが無いときは CPU が入ります。「ひとり」はドン対 CPU。
- M でミュート、Esc で一時停止。結果画面の **もう一回** でもう1ラウンド。

最初のクリックかキー入力で音が鳴り始めます。
